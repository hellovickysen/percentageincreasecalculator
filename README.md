# Percentage Increase Calculator

An Astro website for [percentageincreasecalculator.xyz](https://percentageincreasecalculator.xyz), written for a general US audience.

## Commands

```text
npm run dev
npm run assets
npm run test
npm run build
npm run audit
npm run verify
```

The calculator covers three jobs: compare an original and new value, apply an increase, and recover the original value. All calculator input is processed locally in the browser.

## Launch blockers

- Connect a new GitHub repository; do not use the Age Difference Calculator remote.
- Create and test a Vercel preview.
- Connect the custom domain only after preview approval.
- Add analytics or advertising only after the privacy policy is updated.
